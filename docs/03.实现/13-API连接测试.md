## 1. 目标

目标系统 API 连接 + 自动登录 + swagger 探测。

## 2. 验收标准

- 能按登录策略自动登录拿到 token
- 能探测到 swagger（/swagger/v1/swagger.json 或 /openapi.json，可配）
- 登录失败 / 无 swagger 分别给出清晰提示

## 3. 范围

**In**
- ApiClient（登录策略可插拔：JWT / basic / header token）
- 自动登录拿 token + token 缓存
- swagger 探测（可配路径）

**Out**
- swagger 解析成可配置接口清单（4.2）
- 写接口调用（2.1/3.0）

## 4. 关键实现点

- 登录策略可插拔（适配不同系统鉴权）
- token 在保险库规则下加密存
