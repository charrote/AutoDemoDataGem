## 1. 目标

按 route 标签分发（db / api / compute）+ Run 状态机 + 分块/退避重试/限流/进度。

## 2. 验收标准

- 能按 route 把每条数据分发到 DB / API / 系统自算
- API 失败退避重试；超限 Run 失败且定位到『哪条接口哪条数据』
- 进度（阶段完成度）可查；Dry-Run 先行，确认才真写

## 3. 范围

**In**
- 路由引擎（按标签分发，用户无感）
- Run 状态机：pending → running(phase…) → done | failed | cancelled
- 分阶段执行（主数据→扁平记录→流程/状态→触发重算+自洽校验）
- 分块生成 + 分块落库（可配 batch_size）
- API 退避重试 + 限流
- 进度推送（轮询 / WebSocket）
- manifest 幂等（写前不重复）

**Out**
- 具体连接器（3.0）
- Dry-Run 前端 UI（3.1/4.0）

## 4. 关键实现点

- 『自动选路』= 连接器声明式路由，用户永远看不到『选路』概念
- Dry-Run 先行防误写真实状态
- manifest 保证重试幂等
