# AutoDemoDataGem — 实现跟踪与审计

> 本目录是《02.技术实现方案.md》§9 的**实现级跟踪**：每个任务一张卡片，记录目标 / 验收 / 范围 / 关键实现点 / 进度 / 验证 / 审计。
> **约定**：

> 1. **状态**只有三态：未开始 / 进行中 / 完成。开工前把卡片状态改『进行中』，验证通过改『完成』并填『验证记录』。
> 2. **审计**：每次实质变更（提交代码 / 跑通验证 / 决策变更）都在对应卡片『审计日志』追加一行，带时间戳 + 证据（commit / 命令输出 / 截图路径）。
> 3. **验收**：卡片『验收标准』是完成门槛，逐条打勾（在『进度』里），全绿 + 验证记录有实证才算完成。
> 4. **依赖**：按编号顺序推进；3.0 的 Q1（Swagger）依赖 YOO 确认后由孔明抓取，其余无硬阻塞。
> 5. **不写代码前不动手**：本目录建好、YOO 审阅通过后，再按任务开工。
