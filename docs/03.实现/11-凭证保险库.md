## 1. 目标

目标系统凭证（DB 连接串 / API 凭证）AES-GCM 加密存储 + 脱敏回显 + 无密钥不启动。

## 2. 验收标准

- 加密存 / 解密取（每记录随机 nonce）
- 无 VAULT_KEY 时启动即失败（明确报错，不 fallback）
- API 只回脱敏（末 4 位 / host+port），明文永不出 API、不进日志

## 3. 范围

**In**
- AES-GCM（cryptography）：密文 + nonce + tag 存库
- VAULT_KEY env 单一来源（32B）
- 脱敏回显规则
- 明文只在内存（执行时解密→用完即弃）

**Out**
- 密钥轮换（后续）
- 多密钥管理

## 4. 关键实现点

- 无密钥不生效（明确报错），符合 YOO『单一来源、不设不生效』
- 凭证仅本用户可用（tenant 隔离）
