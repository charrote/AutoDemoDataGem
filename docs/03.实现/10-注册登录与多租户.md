## 1. 目标

注册即用（注册建 tenant）+ JWT + 强制租户作用域隔离。

## 2. 验收标准

- 注册即登录（无需管理员审批）
- 跨租户查询一律 403（repository 强制 tenant_id 作用域）
- JWT 含 sub(user_id) + tid(tenant_id) + exp

## 3. 范围

**In**
- tenants / users 表
- 注册接口（建 tenant + 建 owner 用户 + 签发 JWT）
- JWT 签发 / 校验中间件
- repository 基类 _tenant_scope()：所有查询强制 WHERE tenant_id=?

**Out**
- 角色管理（MVP 只有 owner，预留 member）
- 团队 / 成员管理

## 4. 关键实现点

- 租户隔离是硬约束：杜绝裸表查询，靠基类注入作用域
- 一人一租户（MVP 不建团队概念）
