## 1. 目标

可视化控制台：系统接入 / 选场景 / 调参 / Dry-Run 预览 / 一键运行 / 监控 / 重置。非技术用户一等公民。

## 2. 验收标准

- 非技术用户能走完『接系统→选场景→调参→运行→看效果』
- 运行中：阶段进度条 + 实时日志流
- UI 规范达标（去 AI 味）

## 3. 范围

**In**
- 系统列表 / 新建系统（DB/API 表单 + 连接测试回显）
- 场景 + 参数（滑块 + 数值，非技术友好）
- Dry-Run 预览页（表格 + 预览图）
- 一键运行 + 监控页（进度条 + 日志流，WebSocket/轮询）
- 重置入口

**Out**
- 首启设置向导（4.3）
- Swagger 发现交互（4.2）

## 4. 关键实现点

- 去 AI 味规范：禁 emoji（图标用 SVG）；模态窗 centered+maxHeight；Tab 激活 #3B82F6；状态卡不用左彩色竖条；KPI 卡细边框+语义色数字
