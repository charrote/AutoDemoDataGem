## 1. 目标

按 manifest 一键重置（只清工具灌的）+ 同参数复现同一套。

## 2. 验收标准

- 重置只删工具灌入的数据（按 manifest ID），不动系统真实数据
- 同参数复现：内容一致（值级复现）
- 提供『清空本系统全部工具数据』（按系统维度 manifest 汇总）

## 3. 范围

**In**
- manifest 查询（run_id / system_id 维度）
- 按 ID 删除（DB DELETE WHERE id IN(...) + API 对应删除）
- 值级复现（同 seed 同内容）；ID 钉住为可选增强

**Out**
- ID 钉住增强（schema 允许显式 ID 且需逐 ID 一致时再开）

## 4. 关键实现点

- 只清工具灌的，绝不 truncate 真实数据（安全底线）
- 值级复现已满足『看起来一样 + 可复现』
