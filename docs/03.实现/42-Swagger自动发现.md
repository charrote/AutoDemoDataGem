## 1. 目标

有 Swagger 的系统：自动登录→抓 swagger→解析写接口+schema→『可配置接口』清单（用户勾选+映射）→缓存。占连接器 API 部分约 70%。

## 2. 验收标准

- 有 swagger 的系统自动生成『可配置接口』清单（写接口 + 入参字段/类型 + 鉴权方式）
- 无 swagger 的系统退回手动配 API 映射（连接器声明）
- 首次抓取存 swagger_cache，后续复用

## 3. 范围

**In**
- 登录→抓 swagger（可配路径）
- 解析写接口（POST/PUT/PATCH/DELETE）+ 请求体 schema（字段/类型/必填）+ 鉴权（securitySchemes）
- 前端『可配置接口』清单（勾选 + 字段映射）
- 存入 systems.configurable_ifaces + swagger_cache

**Out**
- 仍需连接器人工标注的部分（哪条是流程/状态型、调用顺序、业务取值、重算触发点、写后自洽校验）

## 4. 关键实现点

- 线上只 Development 开 swagger → 首次抓取缓存（Q3 兜底）
- 自动给 70%（清单/入参/鉴权），人工标 30%（业务语义）
