## 1. 目标

确定性生成『活』数据：固定 seed + 时间锚 + 分布控制 + 引用自洽 + 可控异常。这是产品的灵魂。

## 2. 验收标准

- 同参数两次生成内容完全一致（值级确定）
- 从表外键 100% 指向已生成的主实体 ID（无悬空引用）
- 数值落规格内、状态按真实比例、异常率可控

## 3. 范围

**In**
- seed 派生：sha256(tenant_id|system_id|scene_id|canonical(params)) → numpy default_rng + Faker(seed)
- 时间锚 now：近 N 天铺数据 + 最近 24h 密集『实时尾巴』
- Generator 规格（声明式）：categorical / normal(mu,sigma,spec) / poisson(lam) + anomaly_rate
- 依赖 DAG 拓扑序生成（主→从）
- 异常注入（参数 anomaly_rate，显式可控）

**Out**
- 路由分发（2.1）
- 具体场景配方（3.0）

## 4. 关键实现点

- 所有随机量只从 rng/faker 取 → 全确定（复现的根）
- 引用真实主 ID，杜绝『指向不存在工单』
- canonical(params) 键排序稳定序列化 → 同参数同 seed
