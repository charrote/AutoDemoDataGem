## 1. 目标

Web 先启动 + 数据库 Options（自带 / 已有 MySQL）+ 测试连接 + 建库建表 + 自动切注册页。

## 2. 验收标准

- `docker compose up -d` 仅起 web + api（不依赖 DB）
- 向导选模式→测试连接→初始化→自动切『注册/登录』页
- 『使用已有 MySQL』可连成功（兼容本地/服务器已有 MySQL）

## 3. 范围

**In**
- `GET /api/status` 返回 {initialized, db, mode}
- 向导页：数据库模式二选一（自带 MySQL / 使用已有 MySQL）
- 已有 MySQL：填 host/port/user/password/database + 测试连接（实时回显）
- 初始化：建库 + 建表(migrate) + 写 settings.initialized=1
- 已有 MySQL 权限不足：提供『导出建表 SQL』按钮兜底
- 连接串加密存 settings（保险库规则）

**Out**
- 多租户管理（后续）

## 4. 关键实现点

- web/api 不依赖 DB 启动（首启前置）
- 自带 MySQL 走 builtin-db profile 按需拉起；已有 MySQL 直连外部库
- 连接串只提交一次，此后不回填明文
