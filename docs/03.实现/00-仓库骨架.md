## 1. 目标

初始化 AutoDemoDataGem 代码仓库：monorepo 目录 + 依赖 + Docker 起 web/api（DB 按需 profile，不强制依赖）。

## 2. 验收标准

- `docker compose up -d` 只起 web + api（不依赖 DB）
- `GET /api/health` 返回 200（含 {initialized:false, db:none}）
- .env 密钥占位（VAULT_KEY / JWT_SECRET / MYSQL_ROOT_PASSWORD），不设不生效

## 3. 范围

**In**
- monorepo 目录：api/、web/、connectors/、docker/、.env.example、docker-compose.yml
- Python 3.12 依赖：FastAPI / SQLAlchemy 2.0 / asyncmy(aiomysql) / cryptography / PyJWT / passlib[bcrypt] / numpy / Faker / httpx
- Vue3 + Vite + TypeScript + Element Plus + Pinia + axios + ECharts 骨架
- Compose：web(8860)/api(8000) 先起；db(MySQL 8.0) 进 builtin-db profile 按需

**Out**
- 业务逻辑、前端页面（后续任务）
- 真实数据库初始化（4.3 向导）

## 4. 关键实现点

- web/api 启动不要求 DB 就绪（首启向导前置条件）
- 密钥单一来源 env，无 env 不生效
- 与 MES-v24 命名空间隔离（独立 Compose 项目/端口）
